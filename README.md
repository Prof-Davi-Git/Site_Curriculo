# Criador de Currículos

Versão independente do módulo de currículos do projeto **Meu Futuro Profissional**.

## Recursos

- Não precisa de login.
- Não usa Firebase.
- Funciona somente com HTML, CSS e JavaScript.
- Pré-visualização do currículo em tempo real.
- Foto profissional opcional.
- Formação acadêmica, experiências, cursos, habilidades, competências, idiomas e projetos.
- Rascunho salvo no próprio navegador com `localStorage`.
- Exportação em formato A4 pelo botão **Exportar PDF**.
- 8 opções de cor.
- 6 modelos de currículo: Moderno Lateral, Profissional Visual, Clássico Executivo, Minimalista, Tech e Elegante.

## GitHub Pages

O projeto está preparado para rodar diretamente pelo GitHub Pages porque o arquivo principal é `index.html` e não há dependências externas.

Para publicar, abra **Settings > Pages**, escolha a publicação pela branch `main` e a pasta `/ (root)`.

## Privacidade

Os dados digitados não são enviados para servidor. O rascunho é armazenado apenas no `localStorage` do navegador em que o site estiver sendo usado.
